## Цель работы

Создание консольного приложения «Городской общественный транспорт» для управления маршрутами, транспортными средствами и водителями с использованием ключевых принципов ООП и контроля версий через Git.

## Основной функционал

- **Просмотр списков:** вывод текущей информации о маршрутах и транспортных средствах.
- **Закрепление транспорта за маршрутом:** проверка соответствия вместимости ТС требованиям маршрута.
- **Изменение данных транспорта:** корректировка года выпуска и вместимости.
- **Смена водителя:** назначение нового водителя на транспортное средство.
- **Контроль ограничений:**
  - Вместимость транспорта должна быть не меньше требований маршрута.
