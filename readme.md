## Цель работы

Создание консольного приложения «Городской общественный транспорт» для управления маршрутами, транспортными средствами и водителями с использованием ключевых принципов ООП и контроля версий через Git.

## Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `Driver.h` / `Driver.cpp` | Класс сущности «Водитель» (валидация стажа). |
| `Vehicle.h` / `Vehicle.cpp` | Класс сущности «Транспортное средство» (валидация года выпуска, вместимости, смена водителя). |
| `Route.h` / `Route.cpp` | Класс сущности «Маршрут» (контроль соответствия вместимости ТС требованиям маршрута). |
| `TransportSystem.h` / `TransportSystem.cpp` | Класс-менеджер для управления списками маршрутов и транспорта. |
| `main.cpp` | Меню пользователя, обработчики команд и функции валидации ввода (`inputInt`, `inputString`). |

## Основной функционал

- **Просмотр списков:** вывод текущей информации о маршрутах и транспортных средствах.
- **Закрепление транспорта за маршрутом:** проверка соответствия вместимости ТС требованиям маршрута.
- **Изменение данных транспорта:** корректировка года выпуска и вместимости.
- **Смена водителя:** назначение нового водителя на транспортное средство.
- **Контроль ограничений:**
  - Вместимость транспорта должна быть не меньше требований маршрута.
  - Запрет отрицательных и нулевых значений для вместимости и года выпуска.
  - Запрет повторного закрепления одного ТС за одним маршрутом.
- **Защита от ошибок ввода:** устойчивость к вводу некорректных символов (букв, пробелов и спецсимволов).
