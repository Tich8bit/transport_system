## Основной функционал

- **Просмотр списков:** вывод текущей информации о маршрутах и транспортных средствах.
- **Закрепление транспорта за маршрутом:** проверка соответствия вместимости ТС требованиям маршрута.
- **Изменение данных транспорта:** корректировка года выпуска и вместимости.
- **Смена водителя:** назначение нового водителя на транспортное средство.
- **Контроль ограничений:**
  - Вместимость транспорта должна быть не меньше требований маршрута.

## Основной функционал

- **Просмотр списков:** вывод информации о маршрутах и транспортных средствах (через `operator<<`).
- **Закрепление ТС за маршрутом:** с проверкой вместимости и скорости (через `Route::operator+=`).
- **Открепление ТС от маршрута:** через `Route::operator-=`.
- **Добавление ТС в систему:** через `TransportSystem::operator+=`.
- **Удаление ТС из системы:** через `TransportSystem::operator-=`.
- **Ввод ТС:** через `operator>>` с валидацией.
- **Сравнение ТС:**
  - по госномеру — `==`, `!=`
  - по скорости — `<`, `<=`, `>`, `>=`
  - по году выпуска — дружественная `isNewer`
