# Информационная система «Городской общественный транспорт»

В данном репозитории собраны лабораторные работы по ПнаЯВУ, реализующие объектно-ориентированную модель городского общественного транспорта на языке **C++**, позволяющую управлять маршрутами, транспортными средствами, водителями и контролировать соответствие ТС требованиям маршрута.

## 📌 Вари  ант 16. Городской общественный транспорт

### Описание предметной области

В городе работает несколько **маршрутов** автобусов, троллейбусов и трамваев. Каждый маршрут имеет:
* **Номер** — уникальный идентификатор.
* **Название** — например, «Центральный».
* **Начальную** и **конечную** остановки.
* **Минимальную вместимость** — требования к ТС.

**Транспортные средства:**
* **Автобус** — топливо, объём бака.
* **Троллейбус** — напряжение, расход электроэнергии.
* **Трамвай** — ширина колеи, расход электроэнергии.

**Водители** закрепляются за транспортными средствами.

**Система контролирует:**
1. Соответствие вместимости ТС требованиям маршрута.
2. Уникальность госномеров ТС и номеров маршрутов.
3. Работу с исключительными ситуациями.

## 💻 Функционал программы

* Создание и управление структурой (добавление ТС, водителей, маршрутов).
* Закрепление и открепление ТС за маршрутами.
* Полиморфный подсчёт метрик эффективности ТС.
* Поиск самого результативного ТС.
* Работа с шаблонным контейнером `Collection<T>`.
* Обработка исключительных ситуаций.

## 🛠️ Архитектура проекта (Классы)

Проект спроектирован с использованием ООП и включает следующие ключевые классы:

| Класс | Назначение |
|---|---|
| `Vehicle` | Абстрактный базовый класс ТС |
| `Bus` | Автобус (топливо, бак) |
| `Trolleybus` | Троллейбус (напряжение, расход) |
| `Tram` | Трамвай (колея, расход) |
| `Driver` | Водитель (ФИО, стаж) |
| `Route` | Маршрут (номер, остановки, ТС) |
| `TransportSystem` | Транспортная система |
| `Collection<T>` | Шаблонный контейнер |
| `TransportException` | Базовое исключение + 7 наследников |
